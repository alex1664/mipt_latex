## Создать проект

В терминале VS Code из папки `/home/alex/latex`:

```sh
python3 new-project.py projects/newProject
```

Для названия с пробелами используйте кавычки: `python3 new-project.py "projects/Математический анализ"`.
Существующие папки команда не перезаписывает.

```text
projects/algebra/
├── main.tex             <- название документа и порядок частей
├── preamble.tex         <- пакеты, шрифты, собственные команды
├── sections/            <- текст и формулы по отдельным файлам
│   ├── 01-introduction.tex
│   ├── 02-formulas.tex
│   └── 03-theorems.tex
├── images/              <- картинки
├── .vscode/             <- настройки редактора
├── build/               <- служебные файлы и PDF для просмотра в редакторе
└── main.pdf             <- готовый документ после успешной сборки
```

## Писать и собирать

**Ctrl+S** сохраняет файл и собирает
`main.tex` именно его проекта;

**Ctrl+Alt+B** запускает сборку вручную.

**Ctrl+Alt+V** открывает PDF активного проекта в VS Code.

Чтобы добавить часть, создайте, например, `sections/04-limits.tex`:

```latex
% !TeX root = ../main.tex
\section{Пределы}
```

В `main.tex` перед `\end{document}` добавьте:

```latex
\input{sections/04-limits}
```

Для `sections/topic/part.tex` нужен `../../main.tex`.
Пути в `\input` и `\includegraphics` задавайте от папки проекта.

Русский язык и XeLaTeX уже настроены. Для заготовок формул наберите `mm`
(отдельная формула), `ff` (дробь), `aln` (несколько строк) или `thm`
(теорема), затем **Ctrl+Space → Enter**. Между полями — **Tab**.
Ошибки сборки: «Вывод» → LaTeX Workshop.

Сборка выполняется в два шага: `latexmk` завершает все необходимые проходы
в `build/`, затем готовый PDF копируется в корень проекта как `main.pdf`.
Если сборка завершилась с ошибкой, последняя успешная копия `main.pdf`
не заменяется. Просмотр в редакторе использует `build/main.pdf`, рядом
с которым находятся данные SyncTeX для переходов между исходником и PDF.

Общие настройки находятся в `.vscode/settings.json`. Такие же настройки
есть в каждом проекте для открытия его отдельной папкой и в
`.templates/project/.vscode/settings.json` для будущих проектов.
Директивы выбора компилятора `% !TeX program` отключены: сборкой управляет
единый рецепт. Директивы `% !TeX root` в разделах продолжают указывать
основной файл проекта.

Для той же сборки в терминале перейдите в папку нужного проекта и выполните:

```sh
latexmk -xelatex -synctex=1 -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build -auxdir=build main.tex && cp build/main.pdf main.pdf
```

## Короткое определение

```latex
\Def{Множество — совокупность объектов.}
```

Результат: **Опр.** Множество — совокупность объектов.
Команда с большой `D`: строчная `\def` зарезервирована TeX.
Заготовка: `def` → **Ctrl+Space → Enter**. Работает в текущих и новых проектах.

## Теорема и доказательство

```latex
\thm{Название теоремы}{
  Формулировка теоремы.
}{
  Доказательство. Можно писать формулы и несколько абзацев.
}
```

Три поля: название, формулировка, доказательство. Теоремы без нумерации.
Заголовок «Доказательство» и квадрат в конце добавляются автоматически.
Если доказательства пока нет, оставьте третье поле пустым: `\thm{Название}{Текст}{}`.
Для теоремы без названия оставьте первое поле пустым.
Заготовка: `thm` → **Ctrl+Space → Enter**, затем **Tab** между тремя полями.

## Леммы и утверждения

```latex
\lem{Название}{Формулировка леммы.}{Доказательство.}
\utv{Название}{Формулировка утверждения.}{Доказательство.}
```

Оформление как у теорем: красная строка и доказательство без большого
промежутка. Заголовки — «Лемма» и «Утв.», без нумерации.
Название и доказательство можно оставить пустыми: `\lem{}{Текст}{}`.
Заготовки `lem` и `utv`: **Ctrl+Space → Enter**, затем **Tab** между полями.

## Поля страницы

Поля со всех сторон — 15 мм; красная строка не изменена.
Размер можно поменять в `preamble.tex`: `\geometry{margin=15mm}`.
Текущие настройки есть в существующих проектах этой папки и в шаблоне.
Новые проекты через `new-project.py` получают копию шаблона; последующие
изменения шаблона автоматически в старые проекты не переносятся.
