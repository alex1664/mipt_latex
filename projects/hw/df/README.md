# Дифференциальные уравнения — первое домашнее задание

Набор всех решений из `дз1_чат_кураторов.pdf` (42 страницы) с исправлениями,
пояснениями и векторными рисунками. Стиль и настройки сборки взяты из
существующих проектов репозитория.

- `main.tex` — основной файл и порядок разделов.
- `preamble.tex` — общая типографика, русский язык, XeLaTeX.
- `commands.tex` — команды оформления задач и ответов.
- `sections/` — решения и приложение с перечнем исправлений.
- `main.pdf` — готовый документ.
- `build/` — промежуточные файлы, PDF и SyncTeX для редактора.

Сборка из этой папки:

```sh
latexmk -xelatex -synctex=1 -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build -auxdir=build main.tex && cp build/main.pdf main.pdf
```

В VS Code сохранение файла запускает ту же сборку. Нумерация и состав задач
сохранены по рукописи, а не заменены списком из программы другого года.
Особые случаи № 55 и Д. 5 пояснены непосредственно в документе.
