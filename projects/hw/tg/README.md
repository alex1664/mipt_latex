# Теория групп — первое домашнее задание

Переработаны все 30 страниц файла «дз1_чат_кураторов.pdf». Номера задач
сохранены; повторы объединены; ошибки исправлены, пропущенные переходы
расписаны. В PDF есть оглавление, указатель соответствия страницам исходника
и список существенных исправлений.

## Файлы

- `main.tex` — основной файл многофайлового проекта.
- `preamble.tex` — предоставленная преамбула с проверкой наличия шрифтов.
- `commands.tex` — дополнительные математические обозначения.
- `sections/` — определения, пять тематических разделов и редакционные примечания.
- `main.pdf` — готовый документ после успешной сборки.
- `build/` — служебные файлы и PDF для просмотра с SyncTeX в редакторе.

## Сборка

Нужен XeLaTeX и обычные пакеты TeX Live/MiKTeX: `fontspec`, `babel`
(русский язык), `amsmath`, `amssymb`, `amsthm`, `mathtools`, `geometry`,
`graphicx`, `tikz`, `hyperref`.

Из корня проекта:

```sh
latexmk -xelatex -synctex=1 -interaction=nonstopmode -halt-on-error -file-line-error -outdir=build -auxdir=build main.tex && cp build/main.pdf main.pdf
```

Технические настройки совпадают с проектом `diskran`: та же преамбула,
шрифты CMU, русский Babel и настройки LaTeX Workshop.
Сборка в редакторе использует рецепт `latexmk (xelatex) + main.pdf`:
сначала полностью собирает документ в `build/`, затем копирует готовый
PDF в корень проекта. При ошибке последняя успешная копия сохраняется.
Директивы выбора компилятора `% !TeX program` отключены в настройках.
Команды из `commands.tex` относятся к содержанию задач по теории групп.

## Важные уточнения содержания

- 57.13, б: в самом приложенном задачнике опечатка; вращения куба образуют
  `S_4`, а не `A_4`. Исправлено с доказательством.
- 58.30, г: буквальная запись `R*/Z_+` не задаёт факторгруппу, если `Z_+`
  — положительные целые числа. Это явно отмечено; отдельно решена
  естественная исправленная постановка `R*/R_{>0}`.
- Т.3: приведены оба смысла «самосовмещения» октаэдра: вращения и все
  изометрии. Таблицы и формулы относятся к граням, а не к рёбрам.
- 57.7: комплексные эрмитовы формы сохраняют инерцию; ответ для
  комплексных симметричных билинейных форм указан отдельно.
